# Manage My Batch

Free, browser-based generators for SEO, developers and business owners. Static HTML/CSS/JS —
no build step, no framework, no dependencies. Deploy by uploading the folder anywhere.

## Structure

```
index.html              Home page (live search, categories, featured + all tools)
tools.html              All generators, filterable by category
about/faq/contact/blog/privacy/terms/disclaimer.html
robots.txt, sitemap.xml Generated by build-pages.js
assets/css/style.css    Design system (single stylesheet)
assets/js/site.js       Tool registry, page shell, shared helpers
tools/*.html            One self-contained page per generator
build-pages.js          Regenerates the static pages + sitemap (node build-pages.js)
```

## Shared modules

- `assets/js/site.js` — tool registry, page shell (`GT.page`), output panel, clipboard,
  download, URL/XML helpers. **Adding a tool starts here.**
- `assets/js/fake.js` — `GTFake`: seeded reproducible fake-data engine (40 field types)
  shared by the JSON / CSV / SQL / JSON-array generators. Dates are offset from a fixed
  `REF_DATE` constant, not `Date.now()`, so a seed reproduces byte-identical output forever.
- `assets/js/httpreq.js` — `GTReq`: the shared request form + model behind the cURL,
  Fetch and Axios generators, so all three describe the same request.
- `assets/js/seqid.js` — `GTSeq`: token-driven structured-identifier engine behind all ten
  business numbering tools. Tokens (`{PREFIX}`, `{SEQ:5}`, `{YYJJJ}`, `{FY}`, `{RAND:4}` …),
  Luhn / mod-97 / mod-11 check digits, the primary+more results panel, export formats and
  shared validation. Check-digit and date maths are verified against published test vectors.
- `assets/js/roster.js` — `GTRoster`: classroom engine behind the education tools. Name parsing
  (strips pasted numbering, de-duplicates), seeded shuffle, round-robin no-repeat pairing,
  balanced grouping with keep-apart / keep-together constraints, and a print-window helper.
  Algorithms are unit-verified: round-robin yields exactly C(n,2) unique pairings with no repeats.
- `assets/js/worksheet.js` — `GTWorksheet`: printable worksheet layout with auto-generated answer
  key pages, seeded RNG, fraction maths (gcd/simplify/lcm + typeset fraction HTML), and SVG
  builders for analogue clocks, number lines and coordinate grids. The clock hour hand moves
  proportionally (3:30 → 105°, verified in the rendered SVG), which most printables get wrong.
- `assets/js/schedule.js` — `GTSched`: tournament seeding with correct bye placement, round-robin
  fixtures with home/away alternation, constrained derangements (single-cycle Secret Santa draws)
  and Latin-square rotations. 84 unit assertions cover seed-order properties, bracket invariants,
  fixture uniqueness, derangement correctness and rotation fairness.

## Adding tool #11

1. Add an entry to the `TOOLS` array in `assets/js/site.js` (slug, name, desc, cat, icon, tone, kw).
   This alone puts it in the nav, home page, search index and category filter.
2. Copy any file in `tools/` as a starting point. The page needs three hooks:
   `<section class="hero" id="hero">`, your markup inside `#toolApp`, and `<div id="afterTool">`.
3. At the bottom of your script call `GT.page({ slug, lede, steps, guide, related, faqs })` —
   it renders header, hero, how-it-works, guide, related tools, FAQ, footer and structured data.
4. Re-run `node build-pages.js` to refresh `sitemap.xml`.

Useful shared helpers on `GT`: `mountOutput()`, `copy()`, `download()`, `toast()`, `normUrl()`,
`isValidUrl()`, `xmlEsc()`, `lines()`, `uniq()`, `bytes()`, `byteLen()`, `today()`.
